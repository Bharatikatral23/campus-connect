# CampusConnect (Full Stack) - runs inside VS Code

1. Install Node.js (nodejs.org) and VS Code
2. VS Code -> File -> Open Folder -> choose THIS folder (the one containing server.js)
3. Press F5 (or Run -> Start Debugging)
   The server starts and Chrome opens the site automatically.
4. Admin login: admin@campus.com / admin123
To stop: click the red square in the debug toolbar.
